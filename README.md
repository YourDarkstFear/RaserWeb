# Raser Web — Modern Music Sharing & Player Interface

This web application is the companion web player and link-sharing destination for the [Raser](https://github.com/YourDarkstFear/Raser) desktop music application.

---

## 🔀 Redirection Without Parameters

If a user visits the root page without any song parameters (e.g. directly going to `/`):
- No audio will play.
- The user is immediately and automatically redirected to **[https://github.com/YourDarkstFear/Raser](https://github.com/YourDarkstFear/Raser)**.

---

## 🔍 `/search` Song Search & Link Generator

Accessing `/search` opens the full Material You search experience:
- Search YouTube Music / iTunes for any song, artist, or album.
- **Direct YouTube URL Support:** Paste any YouTube or YouTube Music link (e.g. `https://www.youtube.com/watch?v=...` or `https://youtu.be/...`) to automatically fetch cover art, title, artist, and duration.
- Preview songs instantly using the floating bottom mini-player.
- Copy shareable Raser links with one click or open directly in the full animated player.

---

## ⚡ 7-Character Short Links (`/s/:code`)

All share links generated by clicking **"Copy Link"** on `/search` or within the web player are automatically converted to clean 7-character short links:

- **Format:** `https://raser.iloveteto.com/s/wORozJ0`
- **Instant Preload:** The server injects track metadata directly on arrival with zero client delay.
- **Deduplication:** Generating links for the same track always returns its existing short URL.
- **API Endpoint:** `POST /api/shorten` (`{ n, a, url, img, dur, t }` -> `{ success: true, code, url }`).

---

## 🎵 Full Share Link Format (Legacy / Direct)

Long parameter share links continue to be 100% supported:

| Parameter | Description | Example |
| :--- | :--- | :--- |
| `n` | Song Title | `Falling+Tears` |
| `a` | Artist Name | `KPHK` |
| `url` | YouTube / Media URL | `https://www.youtube.com/watch?v=vONIbZISu9A` |
| `stream` | Direct Audio Stream (.mp3, .m4a, etc.) | `https://.../audio.mp3` *(Optional)* |
| `img` | Album Artwork / Thumbnail URL | `https://i.ytimg.com/vi/vONIbZISu9A/hqdefault.jpg` |
| `dur` | Duration (seconds) | `201` |
| `t` | Media Type | `music` |

### Example Working Share Link:
```text
https://raser.iloveteto.com/?t=music&n=Falling+Tears+(Slowed)&a=Release&url=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DvONIbZISu9A&img=https%3A%2F%2Fi.ytimg.com%2Fvi%2FvONIbZISu9A%2Fhqdefault.jpg&dur=180
```

## 🧠 Player Capabilities Integrated from Raser

1. **Multi-Source Playback with Fallback:**
   - Plays direct audio streams via native HTML5 Audio if available.
   - Plays YouTube streams seamlessly via the background YouTube Iframe API.
   - Automatically detects invalid/unplayable IDs and resolves the correct track via YouTube search.
2. **MediaSession API (System & Lock Screen Integration):**
   - Displays song title, artist, album (`Raser`), and artwork on Windows, macOS, Android, and iOS lock screens and notification centers.
   - Synchronizes lock screen play/pause buttons and scrubbing progress bar.
3. **Desktop Keyboard Shortcuts:**
   - **Space:** Play / Pause
   - **Left / Right Arrow (← / →):** Seek 5 seconds backward / forward
   - **Up / Down Arrow (↑ / ↓):** Volume ±5%
   - **M:** Mute / Unmute
   - **L:** Toggle Synced Lyrics
4. **Browser Autoplay Compliance:**
   - Automatically starts playback upon page load where allowed.
   - Seamlessly starts playing on the user's first gesture without invasive dialogs or banners.
